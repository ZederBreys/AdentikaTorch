# Ручные тесты (в запущенной игре)

Правило: результат записывается сюда с датой и версией сборки. «Не проверено» — пока не проверено руками.
Сборка для теста: `build/libs/torch-automation-<версия>.jar` → `mods/` инстанса рядом с `meteor-client-0.5.8.jar`.
Мир: **одиночный, творческий, Overworld**, отдельный тестовый мир (`/gamerule doDaylightCycle false`, `/time set midnight`).
